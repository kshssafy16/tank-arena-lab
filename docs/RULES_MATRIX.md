# Rule evidence matrix

`확인됨`은 문서 또는 정적 코드의 해당 사실을 확인했다는 뜻이다. `관찰됨`은 사용자 전달 관찰, `추정`은 명시적 연습 정책, `미검증`은 원본 실기 차등 검증이 없는 범위다. 정적 확인을 실기 관찰로 표시하지 않는다.

| rule_id | manual_evidence | observed_v1.3 | simulation_behavior | parity_status | confidence |

| exam.sequence | p15~16: 한 코드/연결, 1~6 각 2회 | 진행 메서드 분기 정적 확인 | 동일 소켓에 다음 지도 응답, 12회 E2E | 흐름 확인됨 / 원본 실기 미검증 | 높음 |
| exam.minimum | p16: 두 시도 최저 별 | 최저 별 갱신 분기 정적 확인 | 두 시도 min, 첫 성공은 임시 표시 | 확인됨 | 높음 |

개인 프로필은 해당 설치본의 정적 동작을 연습하는 용도다. 원본 맵·초기값과 별점 근거가 없는 외부 캡처를 가져올 때는 `reference_import`의 기본값을 공식 기준으로 해석하지 말아야 한다.
