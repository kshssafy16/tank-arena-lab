# Source and asset provenance

| Content | Provenance | Distribution |
|---|---|---|
| Engine, server, protocol, exam runner, tools, tests | Independently authored in this project | MIT |
| Public six maps and independent terrain schedules | Independently designed practice scenarios | MIT |
| Tanks, trees, rocks, supply symbols, project mark | Programmatically drawn Canvas/CSS geometry | MIT |
| Fonts | User's operating-system fonts / generic fallbacks | No font files distributed |
| Runtime dependencies | Python standard library | No third-party packages bundled |
| Local analysis packages | Separately installed under ignored private directory | Not in product/ZIP |
| Reference maps/manual/IL/logs/bot reports | User-local input and validation evidence | Private only, no rights granted by project license |

No original game graphics, sound, executable, DLL, scene, raw map, logo, or copied client implementation is in the public source. No CDN or remote asset is loaded by the UI. The release scanner deliberately permits text-only source releases. A new binary/image asset requires a deliberate policy update and provenance review before inclusion.
