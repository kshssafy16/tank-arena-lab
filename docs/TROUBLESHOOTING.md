# Troubleshooting

| 증상 | 확인 / 해결 |
|---|---|
| `py` 명령 없음 | Python 3.11+ 설치 시 Launcher 사용, 또는 `python run.py` 직접 실행 |
| 포트 사용 중 / WinError 10048 | 기존 게임과 이전 서버 종료 또는 `--tcp-port` 변경. 예제 봇 `--port`도 일치 |
| UI 열리지 않음 | 서버 출력의 localhost 주소 직접 열기. HTTP 포트도 `--http-port` 변경 가능 |
| 연결 대기만 표시 | Stage/Exam 선택 후 봇을 별도 터미널에서 실행했는지, 주소/포트 일치 확인 |
| 두 번째 봇 연결 거절 | 한 Run의 소유자는 한 소켓. Retry 후 새 봇 하나만 실행 |
| 두 번째 시도에서 엉뚱한 행동 | 지도/체력/탄약/경로를 매 상태마다 파싱. 중간에 INIT을 다시 보내지 않음 |
| 60초 timeout | 상태 수신 후 계산/명령 지연 확인. 줄바꿈 또는 기존 끝 공백을 보내야 함 |
| 메가가 있는데 일반 사격 불가 | 탄약은 별도. `F M` 명시. 빈 탄약은 자동 전환되지 않음 |
| 암호 해독 실패 | 인접 여부와 변환 간격 확인. 공개 간격17, 개인 설정은 근거에 따름 |
| ConnectionResetError | 이미 UI에 확정 결과가 있으면 그 결과 유지. 진행 중이면 단절 실패. 단절만으로 승패 추정 금지 |
| 런타임 오류 메시지가 UI에 없음 | 서버는 봇 프로세스를 실행/소유하지 않음. traceback은 봇 터미널에서 확인 |
| Pause에서 화면이 멈춤 | 다음 봇 명령을 적용 직전에 보류한 상태. 1 Turn 또는 Resume 사용 |
| Reset 후 봇이 종료됨 | Reset은 기존 Run을 취소하고 소켓을 닫음. 초기화 후 봇 재실행 |
| 개인 프로필 없음 | 자신이 가진 캡처를 import. 공개 clone에는 개인 지도가 포함되지 않음 |
| 로컬 서버 오류 | Bot Lab 진단과 터미널 확인. 결과 저장 경로의 디스크 권한/공간도 확인 |

서버는 사용자 코드를 인터넷으로 전송하거나 다른 사용자의 코드를 자동 실행하지 않는다. 자신의 신뢰하는 Python 파일만 자신의 PC에서 실행한다.
