로컬 실행 안내 / Settings
  1. 원본 게임을 종료해 TCP 포트 충돌을 피합니다.
  2. 왼쪽에서 Stage 또는 Exam Simulation을 선택합니다.
  3. 프로젝트 폴더의 터미널에서 표시된 Python 명령을 실행합니다.
  4. 모의평가는 같은 Python 프로세스와 소켓으로 최대 12회를 진행합니다.
  5. 결과는 로컬 runs 폴더에 자동 저장됩니다. Export로 JSON도 받을 수 있습니다.
자신의 봇: 127.0.0.1:8747에 연결 후 INIT nickname과 매 턴 명령을 보냅니다. 포트는 서버의 --tcp-port, HTTP는 --http-port로 변경합니다.
공개판 기본값은 모래 −10HP, 일반 30/메가 70 피해, 사거리 3칸. 보급량 1과 암호 간격 17, 별점 및 턴 제한은 연습용 설정입니다. 적 유닛은 정적 장애물입니다. 정확한 원본 맵·AI·점수와 동일하다고 주장하지 않습니다.
Pause/Step/배속은 연습 전용입니다. Reset은 진행 중 연결을 닫습니다. EOF는 종료 신호이며 성공 여부는 Run Results에서 확인합니다. 연결 해제만으로는 Python 예외 내용을 알 수 없으므로 봇 터미널도 확인하세요.
개인 참조 프로필은 --profile private. 가져온 자료와 결과는 .private_reference에만 저장합니다. 자세한 근거와 한계는 docs 문서를 참조하세요.
